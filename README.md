# Datheon — Data Analytics & Power BI Internship

**Intern:** Mehak Jilani | **Data:** Global Superstore (2015-2018, 9,994 rows)

Datheon Data Analytics & Power BI Internship — EDA, Power BI Dashboards, DAX & Business Insights on Global Superstore data.

## 📊 Key Findings

- **Total Sales:** $2,297,201 | **Total Profit:** $286,397 | **Margin:** 12.47%
- **Technology = Profit Engine** — 17.40% margin, $145,455 profit
- **Furniture = Revenue Trap** — $741,999 sales but only 2.49% margin
- **Discount >20% = Loss** in every band — Total loss -$135,376

## 📁 Tasks

### Task 1 — EDA
Python + Pandas — Cleaning, KPIs, Discount analysis.
- Global Superstore data ko clean kiya, KPIs nikale, Category aur Discount ka profit par asar dekha.
- Key finding: Technology sab se zyada profitable, Furniture ka margin sab se kam.
→ `Task_1_EDA/`

### Task 2 — Power BI Dashboard
Star Schema + DAX + Live Demo.
- Fact_Orders, Dim_Customer, Dim_Product, Dim_Date ka Star Schema banaya.
- DAX measures: Total Sales, Total Profit, Profit Margin %, Prior Year Sales, YoY Growth %, Avg Order Value.
→ `Task_2_PowerBI_Dashboard/`

### Task 3 — Customer Cohort & Churn Analytics
Python + Pandas — Tenure Cohort, Churn Drivers, Retention Recommendations.
- 【entity-IBM¦canonical_name=IBM】 Telco Churn data par baseline churn, tenure cohorts (0-12, 13-24, … 61-72) banaye.
- Churn by Contract, PaymentMethod, InternetService, TechSupport nikala, high-risk segments identify kiye.
→ `Task_3_Customer_Cohort_Churn/`

### Task 4 — Financial Margin Dashboard
HTML / CSS / JavaScript — Segment, Discount Band, Monthly & Country analysis.
- Data: `financial_sample.xlsx` — 700 rows, 2013–2014.
- Net Sales: $118.73M | Profit: $16.89M | Margin: 14.23%.
- Key finding: Enterprise loss-making (-$0.61M, -3.13% margin), Channel Partners most profitable (73.13% margin), Government drives 44% of sales.
→ `Task_4_Financial_Margin_Dashboard/`
